## 1. Цел

Трансформиране на статичния сайт на `https://mufonstars79.github.io/-/` в динамичен сайт с Notion като CMS. Съдържанието се управлява изцяло от Notion; при всяка промяна сайтът се rebuild-ва автоматично и се публикува в GitHub Pages.

Дизайнът (шрифтове, цветова палитра, мобилен изглед) остава непроменен.

### 2.2 Предимства

Елементите на секцията "Как работя". Сортиране по полето Ред.

| Поле | Тип | Описание |
|------|-----|----------|
| Заглавие | title | Кратко заглавие на предимството |
| Описание | rich_text | Едно-две изречения |
| Ред | number | Позиция в списъка (1, 2, 3...) |

**Начално съдържание (4 записа):**
1. Реален Sofia трафик — Практикуваш там, където после ще шофираш — не на пусти площадки.
2. Спокоен темп, ясни обяснения — Без крещене, без паника. Правя грешката разбираема, не срамна.
3. Гъвкаво разписание — Сутрин, следобед, уикенд — намираме час, който ти пасва.
4. Проследяваш напредъка си — След всеки урок знаеш точно какво е наред и какво следва.

### 2.3 Услуги

Замества секцията "Категории". Сортиране по Ред. Популярният запис се показва изпъкнало (голям, тъмен блок), останалите — по-малко под него.

| Поле | Тип | Описание |
|------|-----|----------|
| Наименование | title | Напр. "Категория Б" |
| Цена | rich_text | Напр. "45 лв. / час" |
| Описание | rich_text | Кратко описание на услугата |
| Включено | rich_text | Списък с включени неща, разделени с нов ред |
| Популярен | checkbox | Ако е отметнато → показва се изпъкнало с badge "⭐ Най-търсена" |
| Ред | number | Позиция в секцията |

**Начално съдържание (2 записа):**
- Категория Б · 45 лв. / час · Популярен: да
- Категория С · 60 лв. / час · Популярен: не

**Layout (Вариант C):** Популярният запис — голям тъмен блок с цяло описание и included list. Останалите — малки карти в grid под него. Ако нито един запис не е маркиран като Популярен, всички се показват като малки карти.

### 2.5 Галерия

| Поле | Тип | Описание |
|------|-----|----------|
| Заглавие | title | Напр. "Hyundai i30 2018 G" |
| Снимка | files & media | Прикачен файл директно в Notion |
| Ред | number | Позиция |

**Layout (Вариант C):** Снимки наредени вертикално, пълна ширина, с тъмна caption лента в долната част.

**Важно:** Notion генерира временни URL-и (изтичат ~1 час). При всеки build скриптът изтегля снимките и ги записва в `dist/images/{slug}`. GitHub Pages ги сервира директно.

## 3. Build Pipeline

### 3.1 Конфигурация (.env)

```
NOTION_API_KEY=...
NOTION_DB_TEXTS=...
NOTION_DB_PREDIMSTVA=...
NOTION_DB_USLUGI=...
NOTION_DB_OTZIVI=...
NOTION_DB_GALERIA=...
```

### 3.2 Стъпки на build.js

```
1. Зарежда .env
2. Fetch от Notion (паралелно):
   - Текстове      → { KEY: value }
   - Предимства    → сортирани по Ред
   - Услуги        → сортирани по Ред
   - Отзиви        → всички
   - Галерия       → сортирани по Ред
3. За всяка снимка в Галерия:
   - Изтегля файла от Notion signed URL
   - Записва в dist/images/{slug}.{ext}
4. Генерира dist/index.html чрез template string
   - Запазва целия текущ CSS непроменен
   - Попълва всички секции динамично
5. Копира pictures/ → dist/pictures/
6. Извежда обобщение в конзолата
```

### 3.3 Изходна структура

```
dist/
  index.html        ← целият сайт, генериран
  images/           ← снимки от Галерия (изтеглени при build)
  pictures/         ← статични снимки (кола, портрет)
```

## 4. Deploy — GitHub Actions (Вариант C)

Два тригера:
- **Scheduled:** hourly cron (`0 * * * *`)
- **Ръчен:** `workflow_dispatch` (бутон "Run workflow" в GitHub UI)

Workflow стъпки:
1. Checkout repo
2. `npm install`
3. `node build.js` (с NOTION_API_KEY и DB ID-та от GitHub Secrets)
4. Публикуване на `dist/` в GitHub Pages (чрез `actions/deploy-pages`)
